**Что живёт:** публичная страница (allowlist в `middleware/auth_gate.py` — **только**
`/regions/links` + `/api/regions/vk-links`, остальной интерфейс под сессией) с двумя
вкладками: список сообществ сети и расценки на рекламу.

- **Список:** «Малмыж ИНФО — 5226 — https://vk.com/malmig_info», блоками по областям.
  Подписчики — из `region_member_snapshots`; красивый адрес группы (`screen_name`)
  кэшируется в `Region.config['screen_name']` **той же** ночной таской
  `collect_member_snapshots` (04:00) — новые группы и переименования подхватываются сами.
- **Три сортировки:** алфавит / подписчики / соседство. Соседство — BFS-кольца по
  `Region.neighbors` от выбранного «моего района»; граф едет с сервера **вместе с
  незапущенными районами** (транзитные узлы — иначе цепочка рвётся). Гео (`config.geo`)
  для этого не годится: заполнено у 14 районов из 24.
- **Выбор галочками** + липкая панель: охват, цена по оптовой лесенке, кнопка
  «Скопировать заказ» (готовое сообщение владельцу).
- **Цены** — `config/ad_landing.py` (единственное место правок контента): лесенка
  350 ₽/шт с рубежами 5 → 1300, 10 → 2500 и потолком 5000 ₽ с 18 сообществ; таблица
  считается **на сервере** (`quote_price`, покрыта тестами) и уезжает в
  `<script type="application/json">` — в JS формулы нет, разъехаться нечему.
