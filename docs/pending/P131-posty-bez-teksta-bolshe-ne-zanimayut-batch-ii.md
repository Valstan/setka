`⏱ 2026-09-10 · snooze 0 · fresh · фикс в ветке fix/classifier-notext-crowds-batch, дозор — первые сутки после /reliz`

Найдено в логе воркера: каждый прогон `classifier headless: posts=200 … skipped_no_text=123–179`.
Пост без текста движок не судит, вердикта у него не появляется — и он остаётся «свежим» все
сутки окна, занимая место в батче на **каждом** прогоне. Почти все такие посты `kept`, а `kept`
стоят в очереди района первыми (решение 19.08), то есть садятся в её голову. Замер прода 10.09:
в окне без вердикта 581 пост — 403 с текстом (все `dropped`) и 178 без текста (177 `kept`);
отсеянных с текстом за полные сутки 03–09.09 выпадало из окна без вердикта 107–360, в среднем
~260 из ~900 — аудит отсева (ADR-0004) терял около трети. Фикс: фоновая таска берёт батч через
`fetch_pending(text_only=True)`; облачному `/pending` бестекстовые по-прежнему отдаются.

- ⏳ **Дозор:** (а) в строке `classifier headless:` `skipped_no_text` → 0, рядом строка
  `classifier pending: … без текста N — в батч не идут`; (б) `verdicts` на прогон — сначала
  до ~200 (разбор завала ~400), затем по притоку отсева, ~110 за три часа; (в) у `dropped` с
  текстом `never_classified` за полные сутки → около нуля; (г) токены на вердикт падают
  (сейчас 2500–5000 при чанках в 2–3 поста, 21.08 при полных чанках было ~940).
- ⚠️ **Пересекается с дозором бюджета вывода (секция ниже):** после этого фикса чанки headless
  станут полнее, а потолок `max_tokens` растёт с размером чанка. Счёт `finish=length` у headless
  за неделю, захватившую релиз, смешает две формы чанков — делить по дате релиза.
- Слепую зону самих бестекстовых (~130–250 `kept` в сутки, вердикт получает ~1%) фикс **не
