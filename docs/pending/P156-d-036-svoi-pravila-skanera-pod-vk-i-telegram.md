`⏱ 2026-08-25 · snooze 0 · parked · условие расконсервации: первое ложное срабатывание на живой работе`

Три своих правила в `.gitleaks.toml` (Telegram Bot API, `vk1.a./vk2.a.`, легаси-85-hex),
зеркальная правка `utils/log_redaction.py`, корпус из 35 подсадных
(`tests/test_logging/decoys.corpus`) + ранер настоящим бинарником.

**Замер дефолта оказался жёстче, чем мы докладывали brain'у в августе.** Подсадной написан
**до** просмотра регулярок (амендмент к #167). Дефолтные 195 правил поймали **1 форму из 4**:

| форма | дефолт | со своими |
|---|---|---|
| Telegram в пути URL (как утекло 12.08) | ✖ | ✔ |
| Telegram в обычном `TELEGRAM_TOKEN=…` | ✖ | ✔ |
| `vk1.a.…` в присваивании | ✔ (`generic-api-key`) | ✔ |
| VK-токен в query string | ✖ | ✔ |

**Правило `telegram-bot-api-token` из дефолта не ловит НИ ОДНОГО живого токена:** тело
`A[a-z0-9_-]{34}` требует после первой `A` строго строчные, а у Bot API после двоеточия всегда
`AA`. Мы владели этим гейтом с 12.08 и не знали, что телеграмная половина в нём декоративна.

**Красный показан:** подсадной в индекс → хук → `leaks found: 3`, `exit=1`. Контроль-негатив:
sha256, git-SHA, UUID, base64, длинные id и **наши собственные маски** (`token[:20]`,
`token[:12]`) — не срабатывает ни на одном. История: 618 коммитов, `no leaks found`, exit 0
(зелёный означает «подавления в `.gitleaksignore` на месте», а не «чисто» — 6 настоящих
секретов там лежат).

- ⚠️ **Принятое ложное срабатывание:** легаси-правило без контекстного якоря сработает на любой
  строке ровно из 85 hex. Замер: 0 находок на всей истории. С якорем молча терялся бы токен в
  выводе psql / YAML / `repr` — та же ошибка, что породила оба инцидента. Лечить единичный FP
  строкой в `.gitleaksignore`, **не** сужением правила.
- ⚠️ **Известное ограничение:** дискриминатор легаси-правила — **точная длина 85**. Легаси-токен
  другой длины пройдёт молча. Замерить не на чем: на проде все 36 токенов — новый формат
  (`vk1.a./vk2.a.`, длина 220), легаси не осталось. Правило защищает историю, а не настоящее.
- ⛔ **ID правил не переименовывать** — к ним привязаны отпечатки в `.gitleaksignore`; CI
  сканирует историю целиком, и обесточенные подавления сделают гейт красным на каждом PR.
