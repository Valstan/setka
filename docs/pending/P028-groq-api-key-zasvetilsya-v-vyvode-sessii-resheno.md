2026-08-09 при проверке наличия LLM-ключей я написал в shell `echo "$v: ${val:+set}${val:-<unset>}"` —
для **установленной** переменной `${val:-…}` возвращает значение, и `GROQ_API_KEY` целиком попал в
вывод сессии. Ключ считать скомпрометированным. Владелец решил **не ротировать**: проект уходит с
Groq на DeepSeek.

**Урок для проверки секретов:** печатать только факт наличия и длину. Безопасная форма —
`echo "$v: ${val:+set, len=${#val}}"` без ветки `:-`, либо `[ -n "$val" ] && echo set || echo unset`.
Конструкции `:-` и `:+` в одной строке легко путаются местами, а цена ошибки — секрет в транскрипте.
