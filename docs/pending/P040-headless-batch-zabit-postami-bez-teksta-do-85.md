# ~~🟡 Headless-батч забит постами без текста — до 85 % мест впустую (найдено 2026-09-10)~~ ЗАКРЫТО 2026-09-10 в PR #686

> Запись `P040` реестра [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md). Индекс грепается, запись читается целиком, реестр целиком не читается никогда ([D-097](../../AGENTS.md)).

`⏱ 2026-09-10 · snooze 0 · ✅ ЗАКРЫТО — механизм подтверждён и починен сессией-чипом (fetch_pending(text_only=True)), выкачено на прод 10.09; дозор — в ⏳-секции #686 выше`

Замечено попутно, при разборе бюджета вывода. Сводки `classify_pending_posts` пишут
`skipped_no_text` от 116 (21.08) до 177 (08.09) из 200 постов батча, а вердиктов на прогон
всего 17–80. Вероятный механизм: `service.fetch_pending` исключает только посты, у которых
уже есть вердикт, а `headless.classify_posts` посты без текста пропускает, **ничего не
записывая**. Такие посты остаются «свежими» всё окно `get_source_days()` и каждый прогон
снова занимают места в батче. Подтвердить (повторяются ли одни и те же `lip` между
прогонами), решить с владельцем форму — отсекать их до батча или писать явный вердикт — и
чинить отдельным PR. Прежде чем выбирать, свериться с ADR-0004: лента оператора может
рассчитывать на то, что посты без текста видны.
