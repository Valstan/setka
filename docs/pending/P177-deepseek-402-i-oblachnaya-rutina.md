## Запасной контур уже построен — облачная рутина (этап B, ADR-0003)

**Кода писать не надо.** Классификацию до 12.08 делал scheduled cloud agent на claude.ai/code:
по расписанию забирал батч, классифицировал, возвращал вердикты. Работает **по подписке
владельца, без ключей API**.

Полная настройка и **точный промпт рутины v3** — в

## Почему решено НЕ поднимать её сразу (решение владельца 22.09 — ждать оплаты)

Три замера против немедленного возрождения:

1. **Качество ниже того, что выключилось.** Дистилляция 18.08 сравнила движки на живых данных:
   облачная рутина (06.07–12.08, 40 677 постов) — `hold` **28,9 %**, расхождение с оператором
   **34,9 %**; headless/DeepSeek (12.08–16.08, 4 570) — `hold` **0,4 %**, расхождение **4,5 %**.
2. **`hold` блокирует так же, как `delete`** при `CLASSIFIER_ENFORCE_ENABLED=1` (на проде включён).
   Рутина с 29 % hold снимет со сводок около трети кандидатов — лента заметно похудеет.
3. **Покрытие неполное.** Рутина наполняет вердикты фоново через `/pending`; внутриволновой
   `prepublish` — тот, что сыплет 402 — она не заменяет. Свежий кандидат, которого рутина ещё не
   видела, всё равно уйдёт по обычным фильтрам.

Сейчас сеть публикует по детерминированным фильтрам — это не поломка, а режим, в котором она
работала до ИИ-фильтра.

**Если пауза затянется дольше недели** — поднимать рутину, но тогда заодно решить про
`CLASSIFIER_ENFORCE_ENABLED=0` на время, чтобы её холды не выкашивали ленту.

## Урок процесса (записан намеренно)

Ответ на «чем заменить DeepSeek» **уже существовал и был задокументирован**, а агент вместо поиска
существующего построил новое: адаптер на Anthropic API с официальным SDK, шестью зависимостями и
ценой ~$220/мес — под ключ, которого у владельца нет. PR закрыт владельцем в тот же день.

Сигналы были на руках и прочитаны как историческая справка, а не как готовое решение:
`config/classifier.py` («классификацию делает облачная рутина… а не Claude API»),
`web/api/classifier_ingest.py` («scheduled cloud agent (Claude Code routine), пока нет
`ANTHROPIC_API_KEY`»), и сам `scripts/classifier_routine.py`, **который агент в этой же сессии
запускал** — пробой дистилляции на `/start`.

**Правило:** прежде чем строить интеграцию с внешним провайдером, грепнуть репозиторий и
`docs/ops/` на предмет уже существующего контура под ту же задачу. Инфраструктура, выключенная
полгода назад, выглядит в коде неотличимо от исторической справки — различает их только проверка
живости, и она стоит одну команду (здесь: `curl /api/classifier/pending` → 200).
