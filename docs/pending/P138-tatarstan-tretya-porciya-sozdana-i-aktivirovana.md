🔴 **Короткие адреса НЕ заданы, и выяснилось, что для активации они не нужны.** Памятка
велела завести `vysokaya_gora_info16` и т.д. и обещала, что после этого сработают три
команды. Первая же проба показала обратное: `activate_regions.py` ищет группу **по
короткому адресу**, достраивая его как `<код>_info43` — то есть кировский суффикс, для
Татарстана заведомо несуществующий. Записанный в БД `vk_group_id` скрипт при этом
**игнорирует**. Развязка — форма `код=адрес` с неявным адресом, который ВК даёт каждой
группе: `vysokaya_gora=club241506850`. Он резолвится штатно.

**Правило для следующих порций за пределами Кировской области:** передавать
`код=clubNNN` и не тратить заход на короткие адреса. Они косметика — программно
используется только `vk_group_id`.
