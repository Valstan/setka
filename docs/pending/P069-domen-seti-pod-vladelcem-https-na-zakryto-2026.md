**Что теперь верно.** Сайт САРАФАНА виден **только аккаунтам владельца** и только после
входа через ЕСА. Роль `operator` сама по себе доступа не даёт — решает личность
(`_is_owner` в `middleware/auth_gate.py`: логин из `SETKA_OWNER_LOGINS` **при роли
operator**, либо `vk_user_id` из `SETKA_OWNER_VK_IDS`). Публична ровно одна ссылка —
`/regions/links` (плюс её данные `/api/regions/vk-links`), и обе — **точным** совпадением
пути, а не префиксом. `/services` на этом хосте закрыт (публичная витрина каталога живёт
на `вход.вмалмыже.рф`, туда же ведут кнопки соседей).

**Два входа владельца, оба обязаны работать:** логин/пароль (`valstan`, id 1) и ВКонтакте
(id 2, `vk_user_id=20002978`, роль `radar` — сверено с прод-БД 2026-08-02). Опознание
строго по роли заперло бы владельца снаружи сайта при входе через ВК.

**Почему логин-ветка требует роль.** Границей привилегий стала строка логина, а логин
выбирает регистрирующийся: `POST /api/auth/register` публичен, инвайт-код роздан соседям
и зеркалится в «Карман», а уникальность `login` в Postgres регистрозависима — «VALSTAN»
завёлся бы рядом с «valstan» и прошёл бы как владелец. Закрыто двумя замками: роль в
`_is_owner` (публичная регистрация выдаёт только `radar`) и явный 409 на логин из
allowlist в `web/api/auth.py`. Нашли три независимых критика плана, каждый своей линзой.

**https.** `сарафан.вмалмыже.рф` не апгрейдился на https ни на одном шаге: TLS
терминируется на edge Джино, до бокса всё приходит по http, и `$scheme` в nginx всегда
«http». Замер 2026-08-02 (временный `return 200 "$http_x_forwarded_proto"` в блоке,
снят): edge шлёт `X-Forwarded-Proto: https` для https и `http` для http. Теперь блок
редиректит **при явном `= "http"`** (не «`!= https`» — отсутствие заголовка тогда дало бы
вечный редирект и уронило домен целиком) и передаёт приложению настоящую схему через
`$setka_forwarded_proto`. Сессионная кука `Secure` — по голому http войти было нельзя
вовсе. Оба конфига теперь в git: `config/nginx_sarafan.conf`, `config/nginx_maps.conf`.

⚠️ **Асимметрия пустых env** (запомнить, чтобы не превратилось в инцидент):
`SARAFAN_CANONICAL_HOST=""` **выключает** правило домена; `SETKA_OWNER_LOGINS=""`
означает «не задано» → берётся дефолт (пустое значение не должно оставлять сайт без
владельцев). Разная семантика пустой строки в одном файле — специально задокументирована
в комментариях.
