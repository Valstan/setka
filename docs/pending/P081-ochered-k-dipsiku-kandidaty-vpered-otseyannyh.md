# 🔁 Очередь к Дипсику: кандидаты вперёд отсеянных (решение владельца 2026-08-19)

> Запись `P081` реестра [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md). Индекс грепается, запись читается целиком, реестр целиком не читается никогда ([D-097](../../AGENTS.md)).

`⏱ 2026-08-19 · snooze 0 · fresh · ✅ сделано и задеплоено`

Владелец выбрал приоритет без разгона. В окне свежести было 4893 `kept` против 1388 `dropped`:
22% пропускной способности уходило на посты, которые в сводку не попадут ни при каком вердикте.
`_fair_regional_batch` теперь внутри каждого региона ставит кандидатов на публикацию перед уже
отсеянными. **Отсеянные не исключаются, только смещаются** — иначе сломался бы разбор ложных
отсевов, ради которого ADR-0004 и хранит обе стороны фильтра. Round-robin по регионам сохранён
(тест держит).

Разгон (подъём `CLASSIFIER_PENDING_MAX` / частоты cron) владелец отклонил — при запасе
~50 постов в сутки завал рассасывается медленно, но рассасывается.
