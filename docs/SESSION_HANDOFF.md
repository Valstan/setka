снято. +71 тест, всего 1941.

**3. Портал зарегистрирован** по callback'у, присланному через brain. Секреты — в root-only
файлах на проде, в чат не попадали.

**4. Выхлоп добора источников замерен** (пункт висел с 22.07): Яранск 250→924 (×3.7),

## Открытые вопросы для пользователя

- **Три секрета лежат на проде в root-only файлах, ждут передачи владельцем:**
  1. `ssh setka 'sudo cat /root/esa-portal-2026-07-29.txt'` — `client_secret` Портала.
  2. `ssh setka 'sudo cat /root/esa-sabantuy-2026-07-28.txt'` — секрет Сабантуя (с прошлой сессии).
  3. `ssh setka 'sudo cat /root/ecosystem-keys-2026-07-29-0044.txt'` — `ECOSYSTEM_KEY` и
     `RADAR_INVITE_CODE`; их же раздавать проектам экосистемы (в норме — через vault-комнаты,
     как только появится токен КАРМАНа).
- **Смоук-аккаунт `smoke_esa`** (роль `radar`) заведён саморегом при проверке круга; пароль —
  `/root/esa-smoke-account.txt`. Удалять не стал: это `DELETE` прод-данных (гейт #025), и как
  дежурный смоук-аккаунт экосистемы он полезен. Скажете — уберу.
- **Бэкап прод-env** перед правкой: `/etc/setka/setka.env.bak-2026-07-29-0044`.
- **Два owner-only хвоста по группам батча №3** (Опарино / Луза / Подосиновец): ключи
  `COMM_<id>` через «Управление → Работа с API» и подписка МАМЫ редактором.
- Тема `sosed` (два beat-слота почти без источников), мёртвые категории в пуле `arbazh`
  (это `DELETE` прод-данных), правило про сборы на личные карты — с прошлых сессий, остаётся.
