## Failed approaches (этой нитки)

- **Лечить перекос рубрик через `skip_themes`** — отвергнуто по данным. Корень перекоса — тема
  `addons` («Дополнительно»), 21 из 38 вердиктов, но в ней же 7 нормальных материалов в
  `kultura-sport`, 5 в `novosti`, 2 в `obyavleniya`. Резать тему в отборе = терять большинство
  ради меньшинства. **Правила — правильный слой:** они решают по содержанию поста, а не по ярлыку
  сводки.
- **Копировать hard-exclude каскадных сводок** (`modules/cascaded_bulletin.py` режет `addons` +
  религию) — не подходит: это требование владельца **для области/страны**, а районные сводки
  «Дополнительно» публикуют осознанно. Лента района и портал района — разные витрины, и правило
  одной нельзя механически переносить на другую.
- **Проверять содержимое markdown-правил подстрокой из двух слов** — тест на «воинской славы»
  падал, потому что фраза переносится на другую строку при верстке по 90 колонок. Привязываться
  к однострочному фрагменту (`военно-исторический календарь`).
- **Угадывать канон для неоднозначных тем** (`неопределено`, `мероприятия`, `туризм`) — сознательно
  не делаем. Тихая подгонка под свою догадку — та же беззвучная порча данных, от которой лечим,
  только с другой стороны.

## Не забыть (low-priority)

- 🟡 **Gitleaks** — секрет-сканера в контуре нет вовсе, крупнейший незакрытый техдолг.
- 🟡 **`hold` в поле `theme`** (6 строк) — значение `action`, протёкшее в соседнее поле. Словарём
  не лечится, вопрос к источнику.
- 🟡 **Регистрозависимые логины** — `VALSTAN` и `valstan` разные аккаунты.
- 🛠 **`migrate.py up` снова штатная команда** — бухгалтерия сведена, `up` показывает ровно то, что
  не накачено. Ручной накат мимо раннера больше не нужен; для расхождений есть `mark-applied`.
- 🛠 **Проверка секретов в shell — только факт и длина**: `${val:+set, len=${#val}}` без ветки `:-`.
- 🛠 **Не-ASCII на прод — только файлом** (`scp` / `ssh 'cat >'`), никогда аргументом команды (G235).
  Сюда же python-однострочники с кириллицей: вложенные кавычки через ssh не выживают — слать файлом.
- 🛠 **Прод-скрипты** — `sudo bash -c 'set -a; . /etc/setka/setka.env; set +a; cd /home/valstan/SETKA
  && exec ./venv/bin/python scripts/X.py'`; ad-hoc скрипты начинают с `import database.models`.
- 🛠 **Локальный `pytest`** — `--basetemp=<scratchpad>/pt -p no:cacheprovider`; `PRE_COMMIT_HOME`
  тоже в scratchpad, иначе `InvalidManifestError` на коммите.
