## Failed approaches (этой нитки)

- **Кириллический домен прямо в URL доставки** — `https://вмалмыже.рф/...` в `urllib` падает с
  `UnicodeEncodeError` (latin-1) **до** обращения к сети; в журнале это выглядело как `network` ×18
  при живом сервере. Лечение — `idna_url()` в клиенте ([d09a3ac](https://github.com/Valstan/setka/pull/460)).
  **Не возвращать** кириллицу в URL исходящих запросов; в конфиге она остаётся для человека.
- **Имя ключа `INGEST_KEY_<SITE>`** — предлагал в утреннем плане; отвергнуто в пользу существующей
  конвенции КАРМАНа `<SITE>_INGEST_KEY` (согласована директивой 07-26). Свой синоним секрета —
  новое место расхождения реестра. **Не переизобретать** имена, уже согласованные тремя сторонами.
- **Паблик МАЛМЫЖ-ИНФО как источник конвейера** — отвергнуто по данным: его посты это наши же
  сводки-склейки (2–9 вложений на несколько новостей), пришлось бы разбирать собственную склейку и
  угадывать привязку фото. Источник — пересечение опубликованных сводок и аудита сбора.

## Не забыть (low-priority)

- 🟡 **Gitleaks** — секрет-сканера в контуре нет вовсе, крупнейший незакрытый техдолг.
- 🟡 **Регистрозависимые логины** — `VALSTAN` и `valstan` разные аккаунты.
- 🛠 **Проверка секретов в shell — только факт и длина**: `${val:+set, len=${#val}}` без ветки `:-`.
  Конструкция `${val:-…}` печатает **значение**, если переменная установлена (так утёк Groq-ключ).
- 🛠 **Не-ASCII на прод — только файлом** (`scp` / `ssh 'cat >'`), никогда аргументом команды (G235).
- 🛠 **Прод-скрипты** — `sudo bash -c 'set -a; . /etc/setka/setka.env; set +a; cd /home/valstan/SETKA
  && exec ./venv/bin/python scripts/X.py'`: без `cd` падает на `config`, с системным python — на
  `sqlalchemy`. Токен vault живёт отдельно в `/etc/setka/secrets-token.env`.
- 🛠 **Ad-hoc скрипты на проде** — сначала `import database.models`, иначе маппер падает на `Region`.
- 🛠 **Локальный `pytest`** — `--basetemp=<scratchpad>/pt -p no:cacheprovider`; `PRE_COMMIT_HOME`
  тоже в scratchpad, иначе `InvalidManifestError` на коммите.
- 🛠 **Тесты с обрезкой кириллицы** — считать длину хвоста, а не `count("я")`: буква есть в словах
  «вложения» и «сводки», из-за чего два теста подряд ловили ложные 101 вместо 100.
