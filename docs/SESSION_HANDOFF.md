## Failed approaches (этой нитки)

- 🔴 **Город через API.** `groups.edit` из ВК исчез (`[3] Unknown method passed`, v5.199) — город
  и адрес правятся только в браузере. В итоге город поставил владелец руками.
- 🔴 **Десктопные настройки ВК в скрытой вкладке.** `vk.ru/club<id>?act=edit` при
  `document.hidden` рендерится скелетом, серия перезаходов дала капчу 429. Работает только
  активная вкладка на переднем плане и путь `/club<id>/settings`; мобильный VKUI создания групп
  скрытость переживает, настройки — нет.
- 🔴 **«Сохранить» до подсказки «Адрес свободен».** ВК проверяет адрес асинхронно (~4 с):
  ранний клик сохраняет остальные поля с тостом «Изменения сохранены», а адрес молча отбрасывает.
  Факт — только URL или `groups.getById(fields=screen_name)`.
- 🔴 **Первый клик в поле после навигации не фокусирует** — проверять `document.activeElement`,
  при пустом — `focus()` через JS и повторить ввод.
- 🔴 **Smoke `FAIL PENDING` ×3** — воркер разбирал волну `addons` (77 задач в очереди); по правилу
  сначала `llen celery`, затем повтор — прошло.
- 🔴 **Nizhnekamsk/Uslon: `$$`-кавычки в `ssh … psql -c`** раскрываются удалённым шеллом в PID —
  SQL только файлом через `scp` + `psql -f`.
- 🔴 **`/tmp` в Git Bash ≠ `/tmp` для Windows-Python** — файлы для python класть в scratchpad.
- 🔴 **`setup_groups.py --apply` в foreground** — дольше 10 минут, ssh-таймаут; только `nohup` с логом
  (правило 11.09 подтверждено), лог потом чистить через `sudo rm` (root-owned).
