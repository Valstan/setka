## Failed approaches (этой нитки)

Из раскатки 19.08 — чтобы следующий батч не потерял на этом время:

- **Кликать финальную кнопку по координатам скриншота, снятого не непосредственно перед кликом** —
  две группы молча не создались. Диалог создания сообщества **не попадает в accessibility-дерево**
  (`read_page`/`find` его не видят), а после таймаута CDP `Page.captureScreenshot` следующий кадр
  приходит в другом масштабе — модалка съезжает на ~40px, клик уходит в подложку, она закрывается
  без ошибки. **Снимать свежий скриншот прямо перед кликом**, после любого таймаута — ещё один
  и сверять положение модалки.
- **Проверять, создалась ли группа, по списку сообществ в UI** — врёт: счётчик «Управляемые»
  и плитки отстают. Ground truth — `groups.get(filter=admin)` через API.
- **Считать поле «Адрес» в настройках пустым** — там лежит `club<id>`, и ввод дописывается в хвост
  (`club240944863yurya_info43`). Очищать тройным кликом.
- **Открывать настройки через `vk.com/edit?act=info&gid=<id>`** — URL мёртв, отдаёт «Такой страницы
  нет». Только `vk.com/club<id>?act=edit` или кнопка «Управление» на странице сообщества.
- **Считать «капчу на четвёртой группе» баном** — это разные вещи. Капча измерена трижды и
  предсказуема; бан VALSTAN случался (G151) и заморозил разом ВСЕ community-токены. Вторую порцию
  в тот же день никто не пробовал — данных нет, поэтому не гоним.

## Не забыть (low-priority)

- 🛠 **Список архивированных id** — `/var/backups/setka/archived_ids_2026-08-18.csv` на проде
  (44 177 строк). Откат: `UPDATE content_classifications SET reviewed_at = NULL WHERE id IN (...)`.
- 🛠 **`PRE_COMMIT_HOME` обязателен для `git commit`, а не только для `pre-commit run`** — дефолтный
  `C:\Users\Valstan\.cache\pre-commit` на этой машине битый (`InvalidManifestError`), коммит падает.
- 🛠 **Прод-скрипты проекта требуют env явно:** `sudo bash -c 'set -a; . /etc/setka/setka.env; set +a; …'`
  — иначе `DATABASE_URL is not set`. Под `valstan` файл не читается.
- 🛠 **Ad-hoc скрипты начинают с `import database.models`** — иначе `models_extended` роняет реестр.
- 🛠 **`git add` до `pre-commit run --all-files`** — untracked-файлы гейт не видит.
- 🛠 **Прод: `now()` в psql — MSK, а `created_at` пишется наивным UTC.**
- 🛠 **Не-ASCII на прод — только файлом** (`scp`), никогда аргументом команды (G235). Кириллица в
  SQL — через `psql -f`.
- 🛠 **Локальный `pytest`** — `--basetemp=<scratchpad>/pt -p no:cacheprovider`.
- 🟡 **`VK token is invalid or expired` для группы `-218877712`** — токена с таким `community_id`
  в таблице нет вовсе; никто не смотрел.
