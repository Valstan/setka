## Failed approaches (этой сессии)

- **«CI завис» — на самом деле PR был `CONFLICTING`.** GitHub **не строит merge-ref для
  конфликтного PR**, поэтому `pull_request`-прогонов не появляется вовсе («no checks
  reported», а не красные). Пустой коммит и close/reopen такое не лечат. Одновременный
  **настоящий** major-outage Actions выглядел готовым объяснением и увёл в сторону на час.
  **Работает:** первым делом `gh pr view <N> --json mergeable,mergeStateStatus`; `CONFLICTING/DIRTY`
  → `git merge origin/main`, разрешить, запушить. Урок отправлен в мозг
  ([письмо](../mailbox/to-brain/2026-08-26-a-conflicting-pr-never-starts-ci.md)).
- **Пустой коммит как универсальное лекарство от «CI не стартовал»** — сработал ровно
  один раз (в окне реального инцидента GitHub) и создал ложную уверенность. Не путать
  «событие не породилось» с «событие задержано».
- **`git checkout` в хвосте длинной цепочки команд**, пока по тому же дереву идут фоновые
  прогоны, — коммит уехал на `main` вместо feature-ветки, пришлось переносить `git branch -f`.
  **Работает:** переключение веток — отдельным вызовом, когда фоновых задач по дереву нет.
- **Дефолтный `PRE_COMMIT_HOME`** на этой машине битый (`InvalidManifestError`) — `git commit`
  **молча не создаёт коммит**. Всегда `PRE_COMMIT_HOME=<scratchpad>/pre-commit-home`, и после
  коммита проверять `git log -1`.
- **Black в хуке переформатирует файлы** → коммит снова не создаётся; дозакинуть
  переформатированное и повторить (подтверждалось трижды за сессию).
- **`curl -c/-b` cookie-jar не принимает Secure-куку** с `Domain=.<зона>` при обращении на
  loopback — E2E-скрипты на боксе получали 401 при верном логине. **Работает:** брать значение
  из заголовка `Set-Cookie` и слать `-H "Cookie: …"` вручную.
- **`git stash pop` при недоступном `.pytest_cache`** применяет правки, но оставляет запись
  стеша — проверять `git stash list`, иначе легко получить дубль правок.
- Перенесено и всё ещё в силе: «зелёный прогон гейта» ≠ доказательство отсутствия — сперва
  показать, что умеет краснеть; проверка, чей ответ не меняется при подмене предмета, — не
  проверка; длинные ssh-команды рвутся троттлингом (паузы 40–120 с), кириллица в аргументе
  `ssh` роняет соединение.
