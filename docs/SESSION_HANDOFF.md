- **Разовое исключение из границ проектов зафиксировано:** provisioning-ключ КАРМАНа
  доставался через `ssh karman` с вашего разрешения. Правило `AGENTS.md` «прод соседних
  проектов — не наш прод» осталось нетронутым. Если такие случаи будут повторяться —
  правило стоит переформулировать, а не нарушать повторно.

## Не забыть (low-priority)

- 🛠 **Грабля `git check-ignore -v`:** с `-v` код возврата означает «путь совпал с правилом»,
  включая негативное `!...` — whitelisted файл читается как «игнорируется». Вердикт снимать
  **без** `-v` и по путям к файлам, а не по каталогам.
- 🛠 **Проверка каталога `/services` живьём:** `вход.вмалмыже.рф` в punycode —
  `xn--b1ae3a1a.xn--80adkdyec4j.xn--p1ai`. Без поддомена попадёшь в портал вМалмыже и
  получишь честный 404 не от нас.
- 🛠 **Каталог кэшируется в `sys.modules`** — правка `config/services_catalog.py` без
  `systemctl restart setka` на витрине не появляется, хотя импорт в роуте ленивый.
- 🛠 **Грабля Jinja:** данные в `<script type="application/json">` требуют `|safe` +
  экранирования `<`; тест — на отрендеренную строку, не на контекст.
- 🟡 **У Кикнура доля отсева 43% и почти вся рекламная** — при следующем освежении района
  глянуть источники поимённо.
- 🛠 **Грабля проверки ЕСА:** сессионная кука ставится на `.вмалмыже.рф` — прогон круга
  с `127.0.0.1` всегда уводит на `/login`, гонять по публичному issuer'у.
- 🛠 **Грабля замеров:** в `collected_post_audit.decision` лежат `kept`/`dropped`, а не
  `publish` — «сколько опубликовано» даёт честный ноль.
- 🟢 Каталог сервисов ждёт Портфолио и ТАКСИ — когда у них появится прод.
- 🟡 Ротация `CLASSIFIER_INGEST_KEY` — только вместе с владельцем.
- 🛠 SSH на прод и `git push`/`gh` на этой машине периодически флапают (exit 255 / TLS
  handshake timeout) — ретраить, не диагностировать как отказ команды. В этой сессии
  сработало пять раз; помогает цикл ретраев с паузой 8–12 с.
