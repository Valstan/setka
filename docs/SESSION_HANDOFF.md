## Failed approaches (этой нитки)

- **Негативная проверка теста, ломающая синтаксис, ничего не проверяет.** Убирая
  `logger.info` из `if sent:`, оставил пустой блок — сбор упал по `IndentationError`, и
  «тесты покраснели» означало сломанный файл, а не пойманный дефект. Правильная форма —
  заменить наблюдение на `pass`: синтаксис цел, снято ровно то, что проверяется.
- **Проба секретов по env-файлам даёт уверенный ложный «ничего нет»** — второй раз за три
  дня. Токенов Telegram в `/etc/setka/setka.env` нет вовсе, они приезжают из комнаты КАРМАНа
  в рантайме. Мерить надо через `bootstrap_secrets()` до импорта `config.runtime`.
- **«Ноль неканонических тем» само по себе не доказывает ничего** — тот же ноль даёт
  отсутствующее поле. Проверять положительно: сколько строк вообще имеют поле и совпадают ли
  значения с каноном.
- **`pre-commit` переформатировал файл ПОСЛЕ `git add`** — правка `black` осталась вне
  коммита, дерево оказалось грязным после «успешного» коммита. Проверять `git status` после
  каждого коммита, где хук что-то переформатировал.

## Не забыть (low-priority)

- ⚠️ **Логи на боксе в МСК, а приложение пишет в БД UTC.** Смотришь оба источника рядом —
  разъедутся на три часа; сегодня это стоило одного пустого грепа. Секция про
  `DEFAULT now()` в PENDING про то же.
- ⚠️ **Форма ручного прогона скриптов на проде:** под пользователем прода env не читается, а
  `cd ~/SETKA` под `sudo` уводит в домашний каталог root (и `~` в скрипте — тоже). Работает
  `sudo -n bash -c 'set -a; . <env>; . <secrets-token env>; set +a; cd <абсолютный путь> && ./venv/bin/python …'`.
- ⚠️ **SSH к боксу сегодня рвался часто** (`kex_exchange_identification`, таймауты) — это
  тот же G307 про потерю SYN. Длинные команды гонять в цикле-ретрае, иначе «не ответило»
  читается как «сломалось».
- 🟡 `interval()` замерен на рассылке постов, а не на `groups.edit`.
- 🟡 `PROMO_NETWORK_LIST_URL` подхватывается только после рестарта процессов.
- 🟢 Черновик заказа теряется, если сервер отверг его на «Подтвердить».
- 🟢 Ретенция брошенных фото бота старше двух суток.
- 🟢 Негативная проба сторожа демона (остановка `setka-vk-bot` дольше 15 минут) не гонялась.
