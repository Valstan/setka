## Не забыть (low-priority)

- 🛠 **`pre-commit run --all-files` не видит untracked-файлы.** Список берётся из git,
  поэтому новый файл до `git add` не проверяется вовсе — а отчёт выглядит полным прогоном
  («Passed» напротив каждого хука). Врёт сильнее всего на новом коде. **Правило:** `git add -A`
  перед прогоном гейта. Поймано в этой сессии круг CI.
- 🛠 **`psql -v ON_ERROR_STOP=1` обязателен для миграций с несколькими стейтментами.**
  В 075 `UPDATE` стоял перед `DROP NOT NULL` и упал на первой строке; флаг отбил транзакцию
  целиком и данные уцелели. Без него половина миграции легла бы молча.
- 🛠 **`gh pr merge` не имеет флага `-q`** — команда с ним молча не мержит, а `git checkout main`
  после этого выглядит как успешный merge (файл «откатывается» к версии main). Сверять
  `gh pr view <N> --json state`, а не глазами по рабочему дереву.
- 🛠 **Punycode считать, а не набирать по памяти.** `вход.вмалмыже.рф` → `xn--b1ae3a1a...`;
  выдуманный вариант дал `curl` код `000`, что читается как «хост лежит», а не «опечатка».
  `python -c "print('вход.вмалмыже.рф'.encode('idna').decode())"`.
- 🛠 **Локальный `pytest` без `--basetemp`** в писчий каталог даёт ошибки прав на `C:\Temp`
  (песочница). Прогон: `--basetemp=<scratchpad>/pt -p no:cacheprovider`. Полный прогон
  ~5.5 минут — таймаут Bash по умолчанию (2 мин) его режет, ставить 600000.
- 🛠 `pre-commit` на этой машине падает с `InvalidManifestError`, пока не задан
  `PRE_COMMIT_HOME` в писчий каталог.
- 🛠 SSH и `gh` периодически флапают (TLS handshake timeout) — ретраить, не диагностировать.
- 🟡 У Кикнура доля отсева 43% и почти вся рекламная — глянуть источники при освежении.
- 🟡 Ротация `CLASSIFIER_INGEST_KEY` — только вместе с владельцем.
- 🟢 Каталог сервисов ждёт ТАКСИ; карточка портфолио появится обычным путём онбординга.
