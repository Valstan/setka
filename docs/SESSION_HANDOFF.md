## Failed approaches (этой нитки)

- **Механика SEO-RPG (массовый `wall.post` в чужие группы по ключевым словам)** — отвергнута
  до строчки кода. Четыре независимых причины в шапке [`config/promo.py`](../config/promo.py);
  ключевая — теми же токенами публикуются все 38 районов, и бан уже гасил сеть (G151).
  **Не возвращаться** без нового ресурса токенов и без разрешения правил ВК.
- **`groups.edit` под user-токеном** — так было записано в плане по аналогии с G19/G253.
  Проба показала обратное: у user-токенов метода **нет** (`[3] Unknown method passed`), а
  групповой ключ его **исполняет**. Строить канал оформления надо на COMM-ключах.
  **Не повторять рассуждение «групповой токен слабее»** — оно верно не для всех методов.
- **`groups.addLink` для блока «Ссылки»** — метод удалён у всех типов токенов. Ссылки
  проставляются только руками; автоматизировать нечем.
- **Разовый `UPDATE` хэштегов в миграции** — отвергнут в пользу самозалечивающегося
  генератора: разовая правка воспроизвела бы ровно ту болезнь, которую чинили (13 районов
  настроены захардкоженным списком, 23 новых туда не попали).
