## Failed approaches (этой нитки)

- **`--owner-ids <список>` не работает**, когда список начинается с отрицательного id:
  argparse читает значение как ещё один флаг. Только форма `--owner-ids=<список>`.
- **`+420841463` привязка отвергает** — валидация принимает `-?\d{1,20}`, знака `+` не
  знает. Положительные owner_id личных страниц передавать голыми цифрами. Сама привязка
  положительные id держит — проверено на записи и на энфорсменте по отдельности.
- **Планировать аватар как «одну заливку» — недосчитать втрое:** 4 user-вызова за попытку,
  до трёх попыток.
- **Список регионов «осталось оформить» — не задача, а намерение.** Режим считается по
  живому снимку: из девяти «оставшихся» правок требовали пять, четыре были `spot`.
- **Строка `status=error` — память о прошлом прогоне, а не состояние сообщества.**
  `--force-cover` чинит обложку, но статус не переписывает, и строка висит враньём.
- **`pre-commit run --all-files` не видит неотслеживаемый файл** — прогонять гейты **после**
  `git add`, иначе новый файл проходит мимо, а покраснеет CI.
- **Правка `black_id` под агрегаторов — НЕ ДЕЛАТЬ** (замер 30.08: поле пусто у всех 44
  конфигов, отсев 0 постов за 30 дней при 6.7 млн просмотренных; подробности в PENDING).
- **План «пауза пути + блок стены» для кодов ВК — НЕ КАТИТЬ в прежнем виде** (три
  блокирующих возражения, см. PENDING).
