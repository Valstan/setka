## Следующий шаг

**🎯 Один, и он за владельцем: выбрать `alpha` по витрине.**

Открыть `/classifier` → блок «Витрина рейтинга» → ввести район (например `kirov_obl`, `vp`) →
«Показать». Три колонки — одна и та же выборка при разных значениях показателя степени:

- **0.5** — как сортируется лента сейчас: побеждает отклик в маленькой группе;
- **0.25** — предложенный дефолт, стоит сейчас;
- **0** — чистый охват.

Смотреть 2-3 района. Выбранное значение ставится в `RATING_VIEWS_ALPHA` без деплоя.
**До этого выбора шаг 2 (переключение отбора на рейтинг) не начинать.**

Дальше по цепочке: шаг 2 — отбор топ-N внутри разрешённых вердиктом; шаг 3 — снятие редакционных
фильтров, причём `hard_spam` **не снимается вместе с остальными** (fail-open нейро-фильтра + бан
аккаунта за ретрансляцию скама, G151).

## Не забыть (low-priority)

- 🛠 **Миграции на проде — от `postgres`, не от `setka_user`:** таблицы принадлежат `postgres`,
  `psql "$DATABASE_URL"` даёт `must be owner of table`. Верно:
  `sudo -u postgres psql -d setka -f <миграция>`. И `DATABASE_URL` содержит схему
  `postgresql+asyncpg://`, которую psql не понимает — нужен `${DATABASE_URL/+asyncpg/}`.
- 🛠 **JS в шаблонах не покрыт ничем** — проверять `node --check` на вырезанном `<script>`.
- 🛠 **`PRE_COMMIT_HOME` обязателен для `git commit`**, а не только для `pre-commit run`.
- 🛠 **Bash-heredoc падает «unexpected EOF» на backticks/кавычках** — многострочный код писать
  файлом; SQL на прод — файлом через `psql -f`.
- 🛠 **Ad-hoc скрипты начинают с `import database.models`** — иначе `models_extended` роняет реестр.
- 🛠 **Прод-скрипты требуют env явно:** `sudo bash -c 'set -a; . /etc/setka/setka.env; set +a; …'`.
- 🛠 **Локальный `pytest`** — `--basetemp=<scratchpad>/pt -p no:cacheprovider`.
- 🛠 **Прод: `now()` в psql — MSK, а `created_at` пишется наивным UTC.**
- 🛠 **Не-ASCII на прод — только файлом** (`scp`), никогда аргументом команды (G235).
- 🟡 **`VK token is invalid or expired` для группы `-218877712`** — токена с таким `community_id`
  в таблице нет вовсе; никто не смотрел.
