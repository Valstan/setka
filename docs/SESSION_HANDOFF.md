## Не забыть (low-priority)

- 🟡 **Gitleaks** — секрет-сканера в контуре нет вовсе, самый крупный незакрытый техдолг.
- 🟡 **Регистрозависимые логины** — `VALSTAN` и `valstan` разные аккаунты; миграция с `lower(login)`
  + гейт #025.
- 🟡 **Рекламная рубрика ре-транслирует чужие агрегаторы** → риск бана VK.
- 🟡 **Ротация `CLASSIFIER_INGEST_KEY`** — только в присутствии владельца.
- 🟢 **Поштучные услуги лендинга** — сверить с реальностью. 🟢 **ТАКСИ** — карточка в каталоге.
- ⏱ **Ре-триаж напрашивается** (>30 дней в статусе `watch`): Радар-ID Ф2–Ф3 (⏱ 30.06, ждёт хода
  trener → скорее `parked`) и Discovery dead/dormant (⏱ 30.06, работа выполнена → скорее закрыть).
- 🛠 **Не-ASCII текст на прод — только файлом (`scp` / `ssh 'cat >'`) или через веб-форму**, никогда
  аргументом команды: кодовая страница консоли молча съедает кириллицу. Отправлено в мозг как
  находка (`mailbox/to-brain/2026-08-08-cyrillic-lost-in-ssh-argv.md`).
- 🛠 **`pre-commit run --all-files` не видит untracked-файлы** — `git add -A` перед гейтом.
- 🛠 **Локальный `pytest`** — `--basetemp=<scratchpad>/pt -p no:cacheprovider`, таймаут 600000;
  `PRE_COMMIT_HOME` тоже в scratchpad (глобальный кэш pre-commit на этой машине битый:
  `InvalidManifestError`).
- 🛠 **Прод после `systemctl restart`** отвечает не сразу — health-curl в ту же секунду даёт `000`.
  Ждать в цикле, а не объявлять аварию.
