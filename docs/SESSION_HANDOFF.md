## Failed approaches (этой нитки)

- **Набор длинного сообщения в поле ВК одним `type` с переносами.** Enter отправляет; переносы
  только `shift+Return`, а кадр обязателен **до** Enter: 12.09 у Кузнецова ушёл текст без
  пробелов и переносов (удалён «для всех», переотправлен). `form_input` в поле сообщений ВК не
  работает (`SPAN is not a supported form input`).
- **Личка с закрытой приватностью.** Цуканова и Давыдова недоступны с личной страницы — не
  ретраить, помечены в `error`.
- **Скриншот/`zoom` на вкладке ВК после зависшего `captureScreenshot`.** Вкладка остаётся с
  масштабом 175 % (viewport 1098×521), кнопки диалогов уходят за край; лечится только новой
  вкладкой. Клавиатурный обход кнопки «Создать сообщество»: клик в название, `End`, 4×`Tab`, `Enter`.
- **Клик по «Создать сообщество» после первой группы** — трижды не открывал диалог; прямой
  `navigate` на `vk.ru/groups?tab=admin&w=groups_create_new` открывает его без клика.
- **ord.vk.com в расширении Claude in Chrome.** Каждый новый тип действия (клик, ввод, кадр,
  чтение, поиск) спрашивает разрешение отдельно, а внутри `browser_batch` обрывает пакет —
  только одиночные вызовы; закрытое по таймауту окно = «Запретить». Группа вкладок Claude при
  этом трижды исчезала целиком — после каждого сохранения перепроверять `tabs_context`.
- **Скан пула через `sudo` с `~`** — `~/SETKA/venv` раскрывается в `/root`; писать
  `/home/valstan/SETKA/venv`. Скрипты на боксе с моделями — только с `import
  database.models_extended` (иначе `NoReferencedTableError: radar_users`) и `HOME=/home/valstan`.
