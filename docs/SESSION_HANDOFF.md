## Failed approaches (этой нитки)

- **Чинить чужое расширение Chrome `navigate`-ом по кругу.** Чек-лист называл его перемежающимся —
  10.09 оно било на КАЖДОМ действии в диалоге ВК три захода подряд. Помогло одно: владелец
  выключил расширение. Больше двух сбоев подряд — сразу просить его об этом.
- **Считать обрезания по логу через `completion == 220 × k`.** Потолок headless зависит от размера
  чанка, которого в логе нет: у чанка из трёх постов 220 — не потолок. Получилась верхняя граница,
  а не счёт. Настоящий счёт — только по новому полю `finish=` в строке `deepseek-usage`.
- **Проверять адрес группы через `activate_regions.py` до скелета.** Без строки региона в БД скрипт
  отвечает «региона нет» и адрес не проверяет вовсе. Свободу адреса мерить
  `utils.resolveScreenName` через API.
- **Возвращать из `javascript_tool` строку с `location.href`.** Фильтр приватности блокирует ответ
  целиком, если в нём query-строка. Возвращать `location.pathname`.
