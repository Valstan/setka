## Следующий шаг

**Порядок жёсткий — рейтинг ДО встраивания**, иначе отбирать будет не из чего.

1. **Метрики и рейтинг** (не начато). Миграция: колонки `views`/`likes`/`comments`/`reposts` +
   `published_at` в `collected_post_audit` (их там сейчас нет вообще). Таска обновления метрик по
   правилам владельца: **не трогать посты старше 72 часов** и **не трогать уже опубликованные** —
   они в рейтинге не участвуют. Затем отбор топ-N по рейтингу внутри разрешённых вердиктом.
2. **Встраивание отбора в парсер.** `modules/vk_monitor/advanced_parser.py`: принять
   `allowed_lips` + флаг `verdict_mode`. Классификация стадий `_filter_post` уже сделана:
   - **отключить** (редакционные, их заменяет нейронка): `hard_spam` (:474),
     `neighbor_bulletin` (:481), `advertisement` (:484), `blacklist_text` (:491),
     `region_words` (:498), `no_attachments` (:525), тематические (:532);
   - **сохранить** (механика): возраст 72ч (:440), дедуп по lip (:449), чёрный список
     сообществ (:462), дедуп по медиа (:537) и тексту (:551).
   Вызвать `selection.decide_mode` в [parsing_scheduler_tasks.py:292](../tasks/parsing_scheduler_tasks.py:292)
   и [cascaded_bulletin.py:456](../modules/cascaded_bulletin.py:456), режимы:
   `verdicts` → передать `allowed_lips`; `skip-wave` → выйти без публикации; `algorithmic-fallback`
   → нынешнее поведение. Гейт для включения — новый env-флаг, по умолчанию выключен.
3. **Посты без текста.** Решение принято за владельца и им не оспорено: ИИ-фильтр ставит им явный
   `hold` с пометкой «нет текста, вложения не читаются», чтобы они попадали в ленту оператору, а не
   исчезали молча. Сейчас `headless.classify_posts` их просто пропускает (`skipped_no_text`, 18-19
   на прогон) — под звеном 5 это означало бы тихое исчезновение афиш-картинок из лент.

## Failed approaches (этой нитки)

Из разбора 18.08 — чтобы следующая сессия не пошла теми же тупиками:

- **Искать поломку входа в кабинете ВК** — потеряно полдня. Базовые домены были настроены верно;
  добавление punycode-строк бессмысленно (ВК нормализует IDN в кириллицу при сохранении, строки
  схлопываются). Симптом «ВК не пускает» был следствием домена захода, а не настроек приложения.
- **Подозревать пароль / подпись сессии** — тоже мимо. `POST /api/auth/login` отвечал **200**,
  `SETKA_WEB_SECRET` задан, воркер один. Диагноз даёт не форма входа, а **следующий** запрос:
  200 на логин + 302 на любой странице = кука не возвращается, то есть отвергнута браузером.
- **Добавить технический домен в базовые домены ВК-приложения** — не чинит: парольный вход к ВК
  отношения не имеет вовсе, а возврат после ВК-callback всё равно ограничен зоной действия куки
  (`_host_shares_session`) и приземлил бы на issuer.
- **Редирект техдомена в nginx** — построен как план и **отменён**: тот же редирект в приложении
  накрывает и его, одним механизмом вместо двух.
- **Считать качество headless по проценту совпадения с рутиной** (звено 5) — отвергнуто: 33%
  выглядят провалом, но половина расхождения это `hold` рутины (47% потока). Процент совпадения с
  неэталоном не измеряет качество; смотреть матрицу переходов и читать расхождения глазами.
- **Включить headless параллельно с облачной рутиной** — нельзя: запись идемпотентна по `lip`, оба
  источника разбирают одну очередь и воруют друг у друга посты, сверка становится невозможной.

## Открытые вопросы для пользователя

- **Красный прогон gitleaks на подсадном секрете** — приёмка #114 по директиве brain, **срок
  24.08**. Сканер стоит с 12.08 внутри обязательной проверки `test (3.12)`, но зелёный доказывает
  лишь, что он запускается, а не что ловит. Это единственный пункт директивы, который не закрыт.
- **Облачная рутина «⚡ Классификатор текстов Сарафана» — выключена ли?** Headless работает по
  расписанию сам; пока рутина жива, они разбирают одну очередь на двоих.
- **`GROQ_API_KEY`** — отозвать в консоли Groq (скомпрометирован, всё ещё живой) и удалить из
  комнаты КАРМАНа через UI. Пока он в комнате, vault-клиент на каждом старте пишет
  `вне allowlist, проигнорированы: GROQ_API_KEY` — сигнал инцидента превращается в фон.
- **Кириллические redirect URL в кабинете ВК** — добавлялись 18.08 по ложному следу, можно удалить.
- **Rolling discovery** — условие расконсервации наступило (нейро-фильтр есть), слот выключен
  сознательно; включение меняет расход токенов, решение владельца.
- **Базового файла постулатов не существует** — завести или перестать обещать его в докстрингах.

## Не забыть (low-priority)

- 🛠 **Браузером на технический домен провайдера ходить нельзя** — кука зоны туда не отправляется.
  После деплоя #477 страницы уводит автоматически, но закладку стоит переписать на
  `сарафан.вмалмыже.рф`.
- 🛠 **Ad-hoc скрипты начинают с `import database.models`** — иначе `models_extended` роняет реестр
  SQLAlchemy на `'Region' failed to locate a name`.
- 🛠 **`git add` до `pre-commit run --all-files`** — untracked-файлы гейт не видит.
- 🛠 **Прод: `now()` в psql — MSK, а `created_at` пишется наивным UTC.** То же и с
  `vk_tokens.disabled_until` — читается как UTC, в отчёте владельцу переводить в МСК.
- 🛠 **Не-ASCII на прод — только файлом** (`scp`), никогда аргументом команды (G235).
- 🛠 **Локальный `pytest`** — `--basetemp=<scratchpad>/pt -p no:cacheprovider`; `PRE_COMMIT_HOME`
  тоже в scratchpad.
- 🟡 **`VK token is invalid or expired` для группы `-218877712`** — замечено в логе воркера,
  токена с таким `community_id` в таблице нет вовсе; никто не смотрел.
