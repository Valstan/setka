## Failed approaches (этой нитки)

**Сквозная тема сессии: пять раз проверка оказалась не тем, чем выглядела.** Признак у всех
один — **ответ не меняется при подмене предмета**. Ловится одним лишним прогоном с заведомо
неверным входом, стоит секунды.

- **`GET /oidc/authorize` для проверки redirect_uri** — слепа: AuthGate заворачивает на
  `/login` **раньше** валидации ([web/api/radar_id.py:120](../web/api/radar_id.py) против
  `:126-134`). Несуществующий `client_id` с `redirect_uri=evil.example.com` даёт те же **302**.
  **Работает вместо неё:** различение отказов на `POST /oidc/token` — верный секрет + мусорный
  код → `400 invalid_grant`, неверный секрет → `401 invalid_client`. Аккаунт не нужен.
- **Подмена `HOME` для изоляции ssh на Windows** — не изолирует, OpenSSH читает `%USERPROFILE%`.
  Симуляция «машины без ключа» прошла зелёной, пользуясь настоящим ключом с диска.
  **Работает:** `-o IdentityFile=/dev/null`, а `IdentitiesOnly` **не трогать** — он отсекает и
  агентские ключи, то есть глушит ровно то, что проверяешь.
- **Диагностировать сетевую недостижимость одним инструментом.** Объявил КАРМАН недостижимым,
  перепроверив трижды — через прокси, в обход, вне песочницы — и **все три раза тем же curl**.
  Три разных *условия* при одном *приборе* — это одна проверка. По слоям: TCP OK, TLS 1.3 OK,
  Python `urllib` → `401`. Виснет только Windows-curl на schannel из-за TLS-ренеговорота.
  **Не повторять: «проверить сильнее» ≠ «проверить иначе».**
- **Верить, что дефолтный набор gitleaks что-то ловит.** `telegram-bot-api-token` не срабатывает
  **ни на одном живом токене**: тело `A[a-z0-9_-]{34}` требует после первой `A` строго строчные,
  а у Bot API после двоеточия всегда `AA`. Дефолт поймал 1 форму из 4.
- **Считать «Passed» у локального секрет-хука доказательством.** При отсутствии бинарника хук
  пропускает проверку, печатая предупреждение в stderr, — но pre-commit показывает вывод только
  **упавших** хуков. Отличить проверку от пропуска по выводу нельзя. **Проверять:**
  `python scripts/gitleaks_precommit.py --which`.
- **Строить unix-время в тестах через `datetime.timestamp()`** — трактует наивное время как
  местное, на MSK-машине разъезд с `utcfromtimestamp` ровно 3 часа. Брать `calendar.timegm`.
- **Читать `items[0]` у `wall.get`** — первым VK отдаёт закреплённый пост, часто самый старый.
  Живое сообщество объявляется мёртвым. Брать `max` по всем `items`.
- **Мерить по таблице `posts`** — она **пуста целиком** на всём проде; живой конвейер пишет в
  `content_classifications`.

**Перенесено из прошлых сессий, всё ещё в силе:**

- «Зелёный прогон гейта» ≠ доказательство отсутствия — сперва показать, что умеет краснеть.
- Строить проверку копированием правки — она унаследует её слепоту (стоило PR #514).
- `awk 'length>100'` считает БАЙТЫ (на кириллице врёт вдвое); счётчики лога считают волновые слоты.
- Читать статус CI без привязки к SHA — опрашивать `gh run list --json headSha,status`.
