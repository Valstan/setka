## Failed approaches (этой нитки)

- **Верить памятке про короткие адреса.** Чек-лист велел завести `<код>_info16` и обещал,
  что после этого сработают три команды активации. Первая же не сработала:
  `activate_regions.py` ищет группу **по короткому адресу**, достраивая его как
  `<код>_info43` — кировский суффикс, для Татарстана заведомо несуществующий, а записанный
  в БД `vk_group_id` скрипт **игнорирует**. Развязка — форма `код=clubNNN` с неявным
  адресом, который ВК даёт каждой группе. **Для порций за пределами Кировской области
  передавать `код=clubNNN` и не тратить заход на короткие адреса** — они косметика.
- **Десктопный ВК под автоматизацией.** Модалки не открываются вовсе — ни создание
  сообщества, ни «Управление» группой; клик ложится точно в кнопку (рект сходится с
  кадром), `ref` и координаты одинаково безрезультатны, прямые URL `/groups_create` и
  `?act=edit` отдают одну боковую панель. **Работает только мобильный VKUI полной
  страницей** (`m.vk.ru/vkui/community_create`), вложенные шаги — через `location.hash`.
  Оттуда же лимит имени сообщества: **48 знаков**.
- **Ввод текста через `type`.** Теряет пунктуацию молча: «ПЕСТРЕЦЫ - ИНФО | Афиша,
  новости, события» приехало как «ПЕСТРЕЦЫИНФОАфишановостисобытия», инструмент
  отрапортовал успехом. Поймал только счётчик формы (31/48 вместо 41/48). Надёжен
  нативный сеттер `value` + события `input`/`change`, **и поле надо перечитывать по
  значению после каждого ввода**. Разбор ушёл в пул письмом 15.09.
- **`switch_browser` при двух подключённых расширениях.** Отвечает «no other browsers
  available to switch to» и экран выбора не показывает. Рабочий путь — дождаться, пока
  расширение отвиснет, и работать с активным.
