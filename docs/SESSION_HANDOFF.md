## Failed approaches (этой нитки)

- **Верить выводу команды вместо чтения состояния — нельзя, и это стоило четырёх заходов.**
  За день класс #284 «гейт без области» дал шесть инстанций: событие `shown.bs.collapse` на
  элементе, который не `collapse`; ревалидация статики, до которой браузер не доходил, пока
  держал старый документ; отбор ремонта по журналу вместо живого ВК; условие backfill'а,
  не покрывшее занятый адрес; «Сохранить» в ВК, принявшее клик без эффекта; частичная
  перепривязка ключа. **Каждый раз вердикт давало только независимое перечитывание.**
- **Массовая правка без пауз исчерпывает квоту аккаунта.** 40 подряд `groups.edit` закрыли
  канал так, что следующие девять и вся ручная работа в браузере молча перестали срабатывать.
  Следующий массовый прогон — порциями с паузами.
- **Унифицировать описания «под шаблон» вслепую — не повторять.** Авторский текст нёс поисковый
  индекс; замена сняла бы находимость. Останавливались на первой группе и откатывали.
- **Переименование адреса через API невозможно в принципе** — право требует user-токена,
  а метода у user-токенов нет. Проверено обоими токенами в одном прогоне; повторять не нужно.
