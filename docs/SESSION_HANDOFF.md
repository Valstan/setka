## Не забыть (low-priority)

- 🟡 **Gitleaks** — секрет-сканера в контуре нет вовсе, самый крупный незакрытый техдолг.
- 🟡 **Регистрозависимые логины** — `VALSTAN` и `valstan` разные аккаунты; миграция с `lower(login)` + гейт #025.
- 🟡 **Рекламная рубрика ре-транслирует чужие агрегаторы** → риск бана VK; отказ от ретрансляции при повторных банах.
- 🟡 **Ротация `CLASSIFIER_INGEST_KEY`** — делать только в присутствии владельца (одним ходом: ключ + restart + секрет рутины).
- 🟢 **Поштучные услуги лендинга** — сверить с реальностью.
- 🟢 **ТАКСИ** — карточка в каталоге.
- 🛠 **`pre-commit run --all-files` не видит untracked-файлы.** Правило: `git add -A` перед прогоном гейта.
- 🛠 **Локальный `pytest`** — нужен `--basetemp=<scratchpad>/pt -p no:cacheprovider`, таймаут 600000.
- 🛠 **PowerShell + SSH:** inline-python через `ssh setka "python3 -c ..."` ломается — PowerShell парсит код. Писать скрипт файлом, scp, запускать `sudo bash -c 'set -a; . /etc/setka/setka.env; venv/bin/python3 /tmp/x.py'`.
