## Текущая нитка

Гигиеническая сессия: ре-триаж меток старения, просроченный на месяц `/deadcode`, дистилляция и
две прод-операции по прямому разрешению владельца. Инженерная часть закрыта целиком, **осталось
выкатить код на прод**.

Сквозная находка сессии — **три механизма врали молча по одной схеме:** метка старения без статуса
(не всплывает ни как `stale`, ни как `parked`), каталог, забытый в `SCAN_TARGETS` (мёртвое внутри не
ищется, а живое с потребителем внутри выглядит мёртвым), и гейт авто-дистилляции, склеенный с флагом
ИИ-фильтра (условие выглядит гейтом, а работает как «всегда включено»). Во всех трёх автоматика
отчитывалась нормально, а проверяемого условия не существовало.

## Failed approaches (этой нитки)

- **Субагенты в этой сессии массово падали.** Первый прогон триажа потерял 14 агентов на обрывах
  связи, второй (добивка) — все 42 на `403 Request not allowed`, причём мои ретраи только умножили
  отказы. **Урок жёстче:** постобработка при нуле отработавших проверяющих напечатала
  «подтверждён» — то есть скрипт сам совершил ту же ошибку, которую сессия ловила в трёх чужих
  механизмах. **Считай отсутствие голосов отдельным исходом, а не «никто не возразил».**
  Одиннадцать символов пришлось разбирать вручную скриптом-разведчиком (употребления по
  `code/front/scripts/docs/tests` + `git log -S`) — это оказалось надёжнее и быстрее.
- **`sudo bash -c 'cd ~/SETKA …'` не работает** — под `sudo` тильда резолвится в домашний каталог
  root. Рабочая форма: `ssh sarafan "cd ~/SETKA && sudo bash -c '…'"` (cwd наследуется).
- **`ClassificationRule` лежит в `database/models_extended.py`, не в `models.py`**, и скрипту нужен
  ещё `from database import models  # noqa: F401` — иначе SQLAlchemy падает на конфигурации мапперов
  (`expression 'Region' failed to locate a name`).
- **Свежесть файлов на боксе считать по `mtime`, не по имени:** в именах бэкапов env даты врут
  (`bak-20260808-…` создан 07.08, `bak-20260809-…` — 08.08); сортировка по имени затёрла бы не те.
- **`gh pr merge` дважды «падал» на сетевой ошибке, фактически смёржив PR.** Не повторять merge
  вслепую — сверять `git fetch && git log origin/main -1`.
- **Grant в КАРМАНе машиной — невозможно** (server action под сессией владельца с `mfa:true`);
  **`list_gateway_keys.py` / `issue_gateway_key.py` без env не стартуют**; **`--owner-ids=<список>`**
  только через `=`; **VPN `happ-tun` режет SSH** — повтор помогает (за сессию сработало ~6 раз).
- **Правка `black_id` под агрегаторов — НЕ ДЕЛАТЬ**; **план «пауза пути + блок стены» для кодов ВК —
  НЕ КАТИТЬ** в прежнем виде (подробности в PENDING).
