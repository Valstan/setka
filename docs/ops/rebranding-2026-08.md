### Аномалия Кирса — решена

`stats.get` работает под VALSTAN (интервалы, охваты, подписки по дням).
27–28.08 у Кирса: охват 213k+125k, +73 подписки, география — вся Россия.
Источник — пост id 593 (некролог СВО, 653 знака, 2 фото): **436 966 просмотров,
14 559 лайков, 823 комментария** через рекомендации. Контроль: тот же некролог
в той же волне внутри сводки-простыни (пост 592) — **167 просмотров**.
Разница 2600× на одном контенте → этап 3 (хедлайнер) построен на этом замере.

## Осталось

- **Порция 2 автооформления** (~12 full-регионов: mi…zuevka по алфавиту, включая
  murashi/nagorsk/…): бюджет user-вызовов VALSTAN на сегодня израсходован —
  запустить завтра `scripts/setup_groups.py --apply` (идемпотентно, применённые
  пропустит). После — при `error` добить `--repair`.
  ⚠️ Замечание порции 1: у ВК перемежающийся `error 129 Invalid photo` на
  фото-заливках — `--repair` с ретраями добивает со второго прохода.
- **UGC-действия в операторской ленте** (этап 5): сборщик предложки уже работает
  (beat :15, читается user-токеном — проверено), достроить в `/notifications`
  кнопки «одобрить→опубликовать» (`wall.post(post_id=…)` user-токеном) /
  «отклонить» (`wall.delete`) / «автор в ЧС». Публикация предложенного поста —
  только user-токен (community — err 27).
- **Верификация МАЛМЫЖ - ИНФО** (этап 6, owner-шаг): критерии пройдены
  (5316 подписчиков, оформление есть, хедлайнеры дадут оригинальный контент).
  Подача: страница `malmig_info` → Управление → «Отметки сообщества» →
  Верификация → «Подать заявку» (кнопка видна в act=edit).
- **Мониторинг отдачи** (этап 7): beat-таска `stats.get` VALSTAN-токеном
  (reach/reach_subscribers/subscribed по дням) в снимок + график в
  `/subscriber-growth`. Окно оценки ребрендинга — ≥2 недели с 2026-08-29.
- **Статусы сообществ**: в новом интерфейсе групп поля статуса нет ни в
  настройках, ни на странице (проверено DOM) — только у старых пабликов.
  Канал закрыт, не тратить время.

Не судить раньше 7–10 дней; смотреть источник переходов «Результаты поиска
ВКонтакте» и подписки в `region_member_snapshots`; бенчмарк рынка ER≈0,21%.
