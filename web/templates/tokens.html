Ключи сообществ — по одному на группу

Ключ берётся по каждому сообществу отдельно: vk.com/club<ID> → Управление → Работа с API → Создать ключ. Права: «Стена», «Фотографии», «Сообщения сообщества». Раздел «Работа с API» виден только владельцу группы, поэтому слот на группу один; отказоустойчивость даёт каскад ключ сообщества → МАМА → VALSTAN (VITA не публикует никогда). Расход за сегодня

Один инкремент на фактический вызов VK API. Счёт посуточный и обнуляется в 00:00 по Москве — накопительной статистики тут нет. Чтение балансируется по этому счётчику (первым идёт тот, кто сегодня потратил меньше), поэтому у живых user-токенов числа должны быть примерно равны. Строка UNKNOWN:… — расход мимо маршрутизатора, то есть место в коде, которое строит VK-клиент напрямую; это сигнал к правке, а не сбой. Показаны все ключи, включая выключенные — иначе исчезнувшая строка неотличима от нулевого расхода.
