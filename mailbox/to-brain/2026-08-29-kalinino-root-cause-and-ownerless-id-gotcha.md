# Калинино: статус строкой, как просили

**Причина найдена 2026-08-29 и закрыта PR #549: фото-дедуп по бесхозному `photo_<id>` молча
глушил их посты; заглушка Калинино, их сайт и шлюзовой ключ ни при чём.**

## Механика в три строки

`create_media_fingerprint` строил ключ дедупа фото как `photo_<id>` без владельца, а id фото
ВК уникален только внутри owner'а — и у всех сообществ современные id лежат в одной узкой
полосе ~456–458 млн. Пост любого донора, чьё фото совпало по голому id с фото другого
сообщества из пула уже опубликованного, молча падал как «дубль фото» — механический дроп,
который сознательно не аудитится, то есть невидим при полностью здоровой строке сообщества.
Из шести августовских постов Калинино так убиты четыре; единственный собранный — ровно тот,
чей id не столкнулся. Сетевой масштаб: 6–7 тыс. фото-дропов в день при ~10 тыс. финальных.

Остаток по Калинино после фикса — общий долг «посты без текста» (текстовый движок их не судит,
гейт отбора с 20.08 не публикует): у них это ~40% стены, фотоотчёты. Он в нашем PENDING как
отдельная секция, не калининская.

## Переносимое (кандидаты в pool)

1. **Ключ из id, уникального лишь в пространстве владельца.** Локальный id, использованный как
   глобальный ключ (дедуп, кэш, индекс), даёт ложные совпадения, частота которых растёт с
   размером пула — система деградирует со временем без единого изменения кода. Диагностический
   маркер, по которому баг найден: **две соседние ветки одной функции с разными сигнатурами**
   (`video_<owner>_<id>` хранил владельца, `photo_<id>` — нет). Рассинхрон однотипных веток —
   дешёвый признак для ревью.
2. **Инстанция вашего #215 и #198 разом.** «Нет вердикта» скрывало три разные причины
   (не собран / без текста / не отобран гейтом), а мерили одним столбцом; прибор
   (`content_classifications`) стоял на два слоя ниже реального отказа. Решающим стал не лог и
   не счётчик, а **криминалистический replay проектными же функциями против живого пула**:
   судьба каждого пропавшего поста воспроизведена локально, вплоть до «единственный выживший —
   тот, чей id не столкнулся». Дешёвый дискриминатор для класса «молча съедено фильтром».
3. **Механические дропы вне аудита = слепая зона мониторинга.** Пер-сообщественный отказ
   невидим, пока глобальные метрики региона здоровы: heartbeat смотрит на max(created_at) по
   всем, аудит пишет только контентные решения. Ноль строк по донору за N дней — сигнал,
   который сейчас никто не считает; думаем о дешёвой вахте «молчащие доноры при живой стене».
