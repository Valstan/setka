# Выход из ЕСА — есть; клиентам одна строка

Обещал «следующей сессией» — вышло той же. Выкачено на прод 04.09.

## Что стоит

| Что | Где |
|---|---|
| `end_session_endpoint` | в `GET /.well-known/openid-configuration` → `https://xn--b1ae3a1a.xn--80adkdyec4j.xn--p1ai/oidc/logout` |
| `GET` или `POST /oidc/logout` | параметры `post_logout_redirect_uri`, `client_id` **или** `id_token_hint`, `state` (необязателен) |
| Что делает | гасит сессионную куку домена `.вмалмыже.рф` — то есть выход **из всех сервисов сразу**, — и редиректит обратно |
| Куда возвращает | только если **origin** `post_logout_redirect_uri` совпадает с origin любого зарегистрированного `redirect_uri` клиента (путь — любой). Иначе, и без клиента, — своя страница входа с пометкой «Вы вышли из всех сервисов». В чужой адрес ошибкой не отвечаем |
| `id_token_hint` | подпись проверяется, срок — нет (протухший id_token при выходе — норма); `aud` даёт `client_id` |
| Для человека без клиента | на `вход.вмалмыже.рф/login` уже вошедший видит «Вы уже вошли как …» и ссылку «Выйти из всех сервисов» |

Отдельного реестра `post_logout_redirect_uris` не завёл сознательно: зона доверия
клиента уже описана его `redirect_uris`, а вторая таблица с тем же origin — второе
место, где реестр расходится с жизнью.

## Что делать клиентам (портал, ПОЗВОНИ/ТАКСИ, тренер)

В своём «Выйти» после локального logout — редирект:

```
https://xn--b1ae3a1a.xn--80adkdyec4j.xn--p1ai/oidc/logout
  ?client_id=<ваш>&post_logout_redirect_uri=https://<ваш-punycode-хост>/<любой-путь>
```

Или по стандарту — `id_token_hint=<id_token>` вместо `client_id`. Вернётесь на свой
адрес уже без сессии ЕСА; следующий вход спросит её заново. Проверка без браузера:

```
curl -s -o /dev/null -w '%{http_code} %{redirect_url}\n' \
  "$ESA/oidc/logout?client_id=<ваш>&post_logout_redirect_uri=https://<ваш-хост>/"
# → 302 https://<ваш-хост>/   (чужой хост → 302 /login?logged_out=1)
```

## Уведомление о передаче `name`/`email`

На странице входа ЕСА теперь стоит: «Входя, вы разрешаете передавать сервисам
экосистемы ваше имя и e-mail из этого аккаунта». Это закрывает строку 3 моего утреннего
письма (текста не было — теперь есть). Явный consent-экран с галочкой — по-прежнему
Ф2 ADR-0002, только по слову владельца.

Приёмка владельцем: войти в ПОЗВОНИ → на `вход.вмалмыже.рф` нажать «Выйти из всех
сервисов» → ПОЗВОНИ при следующем входе должен снова спросить ЕСА.
