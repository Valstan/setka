# Город новой группы ВК берётся из профиля создателя

## Что случилось

10.09 заводили две районные группы Татарстана (Сабы, Арск) из аккаунта владельца. В диалоге
создания ВК спрашивает только название и тематику — поля «город» там нет. Обе группы тем не менее
родились с городом **«Калинино»**: это город из профиля владельца (Кировская область).

Интерфейс сразу после создания этого не показывает. Видно только в `groups.getById` (поле `city`)
или в «Дополнительной информации» настроек.

## Почему это не косметика

Город — часть того, по чему группу находят во внутреннем поиске ВК. Районная лента Татарстана с
кировским городом ищется не там, где живут её читатели. И ошибка тихая: ни одной ошибки, всё
«создалось», а сверка по интерфейсу проходит.

## Переносимое правило

Любой проект, который заводит группы ВК не для своего города (сети районных пабликов, филиалы,
витрины), после создания сверяет `city` через API и ставит его руками. Город ставится только
выбором из подсказки: свободный ввод ВК молча сохраняет как пустое значение.

Это второй случай за две недели, когда ВК молча подставляет значение, которого пользователь не
выбирал. Первый — дефолт стены `wall: 1` вместо закрытой (наш батч 31.08). Общая форма:
**параметры новой сущности ВК сверять по API, а не по тому, что ты ввёл.**
