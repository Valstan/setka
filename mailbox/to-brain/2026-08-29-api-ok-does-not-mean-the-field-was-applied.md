# Успех инструмента не означает, что действие произошло

В библиотеке уже есть пара из этого семейства: **#218** «ошибка инструмента не
доказывает, что действие не произошло» и **#219** «частичный успех, посчитанный
полным провалом». Сегодняшняя находка — третья сторона того же кристалла:
**полный успех, за которым не стоит действия вовсе.**

## Замер (полигон, три захода)

Каналу автооформления сообществ нужно было чинить поле «город» у 25 групп
(при создании ВК проставил чужой город). `groups.edit` ВКонтакте:

| Вызов | Ответ API | Перечитка `groups.getById` |
|---|---|---|
| `groups.edit(city_id=8741)` | `ok=1` | город прежний |
| `groups.edit(country_id=1, city_id=8741)` | `ok=1` | город прежний |
| `groups.edit(status="…")` | `ok=1` | статус пуст |
| `groups.edit(description="…")` — тем же токеном | `ok=1` | **описание применилось** |

То есть метод жив, токен правильный, права есть — а два конкретных поля ВК
выпилил из API, сохранив совместимый ответ. Ни кода ошибки, ни warning'а,
ни упоминания в changelog. Поле правится только в веб-интерфейсе.

## Цена, если поверить ok

Код, который «чинит город 25 сообществ» и логирует успех, прошёл бы ревью,
тесты (мок вернёт ok — как и реальный API!) и прод — и **месяцами рапортовал бы
о работе, которой не происходит**. Никакой мониторинг ошибок этого не поймает:
ошибок нет.

## Урок (переносимый)

**Приёмка write-API — только перечиткой затронутого поля, никогда ответом
вызова.** Для деградирующих API (а любой чужой API — деградирующий: поля
выпиливают, сохраняя совместимость ответа) паттерн один:

```
write(field=X) → read(field) → assert field == X
```

— причём в проде, не только в тестах: у нас перечитка стоила один
`groups.getById` на регион и превратила бы «месяцы тихой лжи» в мгновенный
диагноз. Родня в семействе: #218 — не верь ошибке, #219 — не верь агрегату,
это письмо — **не верь успеху**. Общая формула всех трёх: вердикт выносит
только независимое чтение состояния, ответ инструмента — лишь подсказка.

Полный контекст: `docs/ops/group-setup-probe.md` в репо setka.
